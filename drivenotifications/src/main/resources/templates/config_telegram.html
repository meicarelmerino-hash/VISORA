Configura tu bot para recibir avisos inmediatos de cambios en Drive.

menu_book Guía de Configuración Rápida
1
Crear el Bot (@BotFather)

Busca a @BotFather en Telegram. Envía el comando /newbot y sigue las instrucciones para ponerle nombre. Al terminar, te dará un HTTP API Token largo.

2
Obtener Chat ID del Grupo

Crea un grupo, agrega a tu nuevo bot y al usuario @IDBot. Escribe /getgroupid dentro del grupo. Copia el número resultante (ej: -10012345678).

Proporcionado por BotFather al crear el bot.
Debe incluir el signo "-" si es un grupo.
